## 生成流程修正

`npm run sync:archive` 现在按以下顺序执行：

1. 解码模型、外观及原始配置。
2. 主目录、成长、魔改军械、魔改成长。
3. 研发、获取途径、装备、强殖、狩猎名单、科技。
4. 网页角色数据及素材、亮星、关卡、剧情／台词、任务、道具。
5. 逐ID覆盖检查。

魔改军械与狩猎名单使用本轮新导出的主目录，避免第一次生成仍读取旧网页ID集合。科技属性／抗性优先读取当前原始数据，避免被旧网页回填已经删除的抗性。狩猎筛选选项固定按任务号排序。

APK查找统一支持 `apks/钢铁华尔兹_YYMMDD.apk`，优先日期较新的文件，再回退旧名称与根目录路径。评估图标按既有工作流优先读取 `apks/base(1).apk`。此次三个非base APK的SHA256相同：`ffc32a85cadf992832ab56fea0bffbdcb1dcb3cf25f4c8fe82ac041d9112e157`；新内容主要来自本地补丁，不能仅替换APK就宣称数据更新完成。
