# 引擎、车体抗性筛选与默认首页

2026-10-31：筛选多个抗性时，默认要求同一个可选引擎同时满足全部引擎抗性，同一个可选车体同时满足全部车体抗性。仍可匹配任意已收录的期数／工艺，不要求只看最高期；引擎与车体分别判断，不能相互补足。

车体抗性下方增加“允许跨引擎／车体匹配抗性”开关，默认关闭。开启后，每类部件各自取全部可选方案的抗性并集，兼容旧筛选方式。单选及没有抗性条件时的含义不变；缺少所需抗性的车辆不会因开启开关而通过。

适用范围：卡牌图鉴、属性表共享的主筛选器；详细信息的排名范围筛选；柱状图／散点图的选车筛选。主筛选器在两个视图之间保持状态，图表初次打开继承主筛选器，随后独立修改；排名范围仍默认重置。开关遵守弹窗“确定／取消／重置”逻辑，重置后关闭；开关本身不计入已选择条件数量。

规则由 `app/resistanceFilters.ts` 的 `matchesCraftResistances` 统一实现。PLZ05（9865）的抗泥沼、广阔适应分属不同车体，默认不能同时命中，开启开关后可命中；WZ-131（6132）的抗冻结、抗起伏同理，分属不同引擎。按当前621位实装记录，车体“抗泥沼＋广阔适应”同部件匹配13位、跨部件匹配50位；这是本次测试快照，不应写死为长期规则。

网站默认打开“卡牌图鉴／方形头像”；钢舞姬子菜单顺序为卡牌图鉴、属性表、研发配方、研发路线。属性表相关回归通过 `scripts/audit-table-setup.mjs` 显式进入属性表，避免依赖首页或菜单下标。

验证入口：

- `npm run verify:resistance-filters`：真实配置的正／反例、空条件、缺失抗性及类别隔离。
- `npm run audit:resistance-filters -- <本地网址>`：图鉴／属性表、图表、排名的完整结果集合、取消／重置、移动端、刷新后的默认方形头像。
- `npm run audit:filters -- <本地网址>`、`npm run audit:filter-scroll -- <本地网址>`、`npm run audit:navigation -- <本地网址>`：原有条件组合、滚动可达及菜单／触摸导航。
- 普通构建和 Pages 构建分别保留在两个本地副本；`verify:pages`、`audit:pages` 验证子路径和默认首页。
