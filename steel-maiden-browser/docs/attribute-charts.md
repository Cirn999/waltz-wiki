# 属性表多车图表

入口位于属性表的等级切换右侧：柱状图、散点图。

## 选择与计算

- 桌面采用可选车辆、待比较车辆、坐标定义三列；窄屏通过顶部三个标签切换。
- 初始继承属性表的等级、分类筛选与搜索文字。之后的图表等级、筛选和待比较列表独立，不改变背景属性表。
- 筛选器复用现有车种、国籍、稀有度、图纸、魔改费用、弹种、抗性、才艺、狩猎任务规则。
- 左侧点击加入，右箭头批量加入当前可见候选；已选车辆不再出现在候选中。中列点击移除，符合当前筛选的车辆重新出现在左列。修改筛选不清空已选列表。
- 中列查找只帮助定位需要移除的车辆，不缩小实际出图范围。
- 坐标支持八维属性或公式：点击插入属性块、加减乘除、括号，支持数字常量与负数；点击块间光标可调整插入位置。
- 数据直接来自属性表该等级的 `maiden.stats[level]`，不含配装模拟配置。表达式使用专门的递归下降解析器，支持优先级、括号和一元正负号，不使用 `eval`。
- 缺失属性、除零或数值溢出会提示具体车名并阻止生成，不用 0 代替缺失值，也不静默丢弃已选车辆。

## 绘图

- 柱状图按 Y 值从左到右降序；圆形头像位于各柱上方，数值位于底部。每车最小横向间距 64px，头像直径 42px。人数增加时扩展整张画布，支持横向滚动；没有车辆数量截断。
- 柱状图支持零与负值，零基线随数值范围定位，数值排序使用未舍入结果。
- 散点图以待比较车辆 X、Y 各自中位数作为原点，刻度表示相对中位数的差值。偶数车辆使用中间两个值的平均数。图中标题显示实际中位数；头像悬停/点击/键盘聚焦可查看实际 X、Y。
- 所有散点保持真实线性位置，不做偏移或角度夸张。完全同坐标的车辆以头像和数量聚合，点击后列出这些车辆的头像、名称和实际数值；间距缩放可放大密集区域。
- 显示最多两位小数（极大或极小数采用科学计数法），定位与排序使用完整数值。

## 分享

“复制图表”把完整 SVG（包括屏幕外的部分）转换为 PNG 并写入剪贴板，不下载文件。头像先内嵌，导出不依赖 SVG 外链图片或页面 CSS。按浏览器画布限制控制输出边长与像素总量，大图整体缩放而不裁剪车辆。截图包含图表类型、等级、公式、数量和散点中位数说明。

## 验证

- `npm run verify:attribute-charts`：表达式解析、异常值、774 辆车 × 4 个等级 × 8 维属性、中位数、排序、完整大图导出尺寸。
- `npm run audit:attribute-charts -- http://localhost:3100`：完整选车、筛选、公式、生成、PNG 编码及剪贴板调用、774 车柱图、同坐标聚合、等级隔离和窄屏操作。剪贴板写入在测试中被拦截，实际生成的 PNG 仍会校验签名与尺寸。
- `node scripts/audit-magic-cost-filters.mjs http://localhost:3100` 和 `npm run audit:table-controls -- http://localhost:3100`：既有筛选与属性表回归。
