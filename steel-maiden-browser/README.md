# 钢舞姬战术档案库

双击 `start-local.cmd`，然后在浏览器打开终端显示的本地地址（通常为 <http://localhost:3000>）。

数据来自测试服静态配置生成的 777 条钢舞姬汇总 JSON。默认进入全量属性表，可按等级和复合条件筛选，所有表头均可升降序排列；也可切换到卡牌图鉴、双车对比、研发科技树和研发关系图。研发视图收录 416 个目标、432 套去重配方、596 套资源消耗方案和 931 条上下级关系，可搜索、按阶段/车种筛选，并正反向查询每辆车的研发前置与后续分支。研发关系图默认为空，指定钢舞姬后才会从上到下生成仅与她相关的完整研发链；共同前置放在同一紧凑框中，主链角色使用较大头像、协同角色使用小头像，选定角色高亮，多条下级路线会通过连续连接线持续分支到各自终点。关系图不限制横向宽度，页面按实际分支数自然扩展；点击头像可跳转到对应的研发科技树详情。每套方案会列出指挥官等级、银币、图纸、带 S 等级的装备及其他材料；同一方案内所有条件为 AND。相同前置组合下的多套资源方案来自不同活动、渠道或时期，数值不累计，实际开放方案以服务器状态为准。

卡牌图鉴默认按内部编号升序展示竖版卡牌，也可整体切换为属性表同款方形头像；两种模式共用搜索与筛选，点击直接打开详细档案。竖版采用已确认的原创金属卡框、游戏稀有度底色、国籍/车种/稀有度图标及军功章费用字符素材，长车名自动适配双行。美术与实现约定见 [卡牌图鉴规则](docs/card-atlas.md)。

资源生成器会优先提取游戏内的单张立绘；遇到旧式 Live2D 分层角色时，会在本地还原模型并生成静态立绘与头像。

角色立绘通过模型配置自动关联并缓存到 `public/art/maidens`；人物头像优先解析游戏 `UIStyle` 与 `roleModelInfo` 的官方头像，缺失时使用游戏立绘缩略图，缓存于 `public/art/heads`。

属性表将车种、稀有度和魔改费用整合到游戏方形头像，名称列分两行显示坦克名与人名。头像与名称固定在左侧；列设置只管理合并后的列，车种、稀有度、图纸和魔改费用仍可独立筛选。头像分层素材由 `npm run prepare:table-portraits` 从 `Head_Square`、`RareType` 和 `CLASS_SMALL_ICON` 配置生成，缓存于 `public/art/table-portraits`，并随 `prepare:data` 更新。弹药列默认位于侦查之后，以 `tkyl-005` 底框和弹种消耗分类的 `FundTypeInfo` 资源 8 图标显示，每行三个，超过三个换行；原版图标居中按 45% 显示，相关素材缓存于 `public/art/table-ammunition`。

首次重新生成数据：

```bat
npm run prepare:data
```

开发运行：

```bat
npm run dev
```
